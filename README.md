# Apps de Matheus

Apps nativos para Mac (Apple Silicon, macOS 26+). Cada pasta é um app com o próprio build:
a cada mudança, o GitHub compila num Mac da nuvem e gera o `.dmg` na aba **Actions**.

| App | O que faz | Baseado em |
|---|---|---|
| [Downloader](Downloader) | Baixa vídeo/áudio do YouTube, Instagram, TikTok, X e outros, e converte para abrir no Premiere | [DownloaderCRTV](https://github.com/noahcrtv1/DownloaderCRTV) + [ConverterCRTV](https://github.com/noahcrtv1/ConverterCRTV) |
| [Music Split](MusicSplit) | Separa voz e instrumentos, detecta BPM, acordes e tom (com correção manual), limpa a voz de falas | [SplitterCRTV](https://github.com/noahcrtv1/SplitterCRTV) |

Os apps originais são de Noah CRTV, sob licença MIT.
